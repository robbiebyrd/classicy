# ClassicyAssistant Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Mac OS 8 (Platinum) "assistant"/wizard component that fills a `ClassicyWindow`'s content area and pages through steps with prev/next navigation, a two-icon header, a body region, and a footer with optional action buttons.

**Architecture:** A single self-contained, uncontrolled React component (`ClassicyAssistant`) rendered as the child of a `ClassicyWindow`. It is a CSS flex column of three regions — header / body / footer. It owns its `currentPage` state internally, exposes an `onPageChange` callback, and gates forward navigation through an optional per-page `canAdvance()`. Presentation lives in a co-located SCSS file using existing Platinum theme variables and appearance mixins. No dependency on window/desktop state — the component is pure and testable in isolation with only the sound hook mocked.

**Tech Stack:** React + TypeScript, Vitest + React Testing Library, SCSS (co-located), Storybook.

## Global Constraints

- Package manager is **pnpm**; run commands via pnpm.
- **No inline layout/presentation styles** — all styling in the co-located SCSS file (CLAUDE.md).
- Do **not** hand-edit barrel `index.ts` files — they are auto-generated by `generate-barrels` during `pnpm build:source`.
- Path alias `@/` → `./src/`.
- `pnpm test` does NOT type-check; run `pnpm build:source` (tsc -b) before finishing to catch type errors.
- Reuse shared primitives: footer buttons use `ClassicyButton` (props: `onClickFunc`, `disabled`, `buttonSize`).
- Page-change sound: `player({ type: "ClassicySoundPlay", sound: "ClassicyTabClickUp" })`. Blocked-advance sound: `player({ type: "ClassicySoundPlayError" })`.
- Max **3** footer buttons; extras dropped with a `console.warn` (no silent truncation).
- Navigation does **not** wrap: prev disabled on first page, next disabled on last page.

```tsx
// src/SystemFolder/SystemResources/Assistant/ClassicyAssistant.tsx
import "./ClassicyAssistant.scss";
import { type FC as FunctionalComponent, type ReactNode, useState } from "react";
import { useSoundDispatch } from "@/SystemFolder/ControlPanels/SoundManager/ClassicySoundManagerContext";

export interface ClassicyAssistantButton {
	title: string;
	onClick: () => void;
	disabled?: boolean;
}

export interface ClassicyAssistantPage {
	title: string;
	labelIcon?: string;
	accessoryIcon?: string;
	accessoryIconSize?: "sm" | "md" | "lg";
	content: ReactNode;
	buttons?: ClassicyAssistantButton[];
	canAdvance?: () => boolean;
}

export interface ClassicyAssistantProps {
	pages: ClassicyAssistantPage[];
	buttons?: ClassicyAssistantButton[];
	initialPage?: number;
	onPageChange?: (index: number) => void;
}

const clamp = (value: number, min: number, max: number): number =>
	Math.min(Math.max(value, min), max);

export const ClassicyAssistant: FunctionalComponent<ClassicyAssistantProps> = ({
	pages,
	initialPage = 0,
	onPageChange,
}) => {
	const lastIndex = Math.max(0, pages.length - 1);
	const [currentPage, setCurrentPage] = useState(() =>
		clamp(initialPage, 0, lastIndex),
	);
	// player is unused until Task 2; referenced now to establish the hook.
	useSoundDispatch();

	const page = pages[currentPage];
	if (!page) return null;

	return (
		<div className={"classicyAssistant"}>
			<div className={"classicyAssistantHeader"}>
				<span className={"classicyAssistantHeaderTitle"}>{page.title}</span>
			</div>
			<div className={"classicyAssistantBody"}>{page.content}</div>
			<div className={"classicyAssistantFooter"}>
				<div className={"classicyAssistantFooterButtons"} />
				<div className={"classicyAssistantNav"}>
					<span className={"classicyAssistantPageIndicator"}>
						{currentPage + 1}
					</span>
				</div>
			</div>
		</div>
	);
};
```
