# Default Alert Sound Preference Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users pick a default alert sound in a new Appearance Manager "Sound" tab (persisted, default Sosumi), and expose an app-wide `ClassicyAlertSound` event + `useClassicyAlertSound()` hook that plays it; the generic `ClassicySoundPlayError` beep also falls back to the selection.

**Architecture:** The persisted selection lives in the Zustand `System.Manager.Appearance.alertSound` slice (written by a `ClassicyDesktopChangeAlertSound` reducer event). The Sound Manager (React Context reducer) gains an `alertSound` field kept in sync from Zustand by the provider, so the pure reducer never reaches across stores. `ClassicyAlertSound`/`ClassicySoundPlayError` play `ss.alertSound`.

**Tech Stack:** React + TypeScript, Zustand, Howler, Vitest + React Testing Library, SCSS.

			<ClassicySoundDispatchContext.Provider value={soundDispatch}>
				{children}
			</ClassicySoundDispatchContext.Provider>
		</ClassicySoundManagerContext.Provider>
