# H 7.1: Full parity re-shoot and docs

## Problem Statement

Every H section ended pixel-identical on its own surfaces; the plan (0011-v9t §7.1 and Phase 8) requires one full re-shoot of the Phase 0 set compared with ImageMagick `compare -metric AE`, a bundle check, and documentation of what changed: the 21 `measurements.<family>` knob families in `platinum.json` and the `bin/check-pixel-literals.ts` gate run by `pnpm lint`.

This story re-shoots `after/`, compares every story and app screen (expected 0 differing pixels), greps the built `dist/classicy.css` for leftover literals, writes the AGENT-REFERENCE §8 'Package knob families' table and 'Pixel literal gate' paragraph, the CLAUDE.md Theming sentence, and the 'Done' lines in plan 0000-aud (the audit) §2.5 and §9 Phase 6 item 3, then runs the Phase 8 final-verification checklist (full gate, independent grep, `verify` skill drive, server cleanup).

**Impact:** Without the full re-shoot a cross-surface regression (e.g. a knob renamed in H 6.1 that H 3.1's strip reads) ships unnoticed; without the docs, later parts and consumers do not know the knob families exist or that `pnpm lint` now fails on a bare `Npx`.

## Steps

### 1: Re-shoot every Phase 0 story and app screen into after/

Shoot the same ids and the four app screens into `.playwright-mcp/parity/part-H/after/`, then `for f in .playwright-mcp/parity/part-H/before/*.png; do printf '%s ' "$(compare -metric AE "$f" ".playwright-mcp/parity/part-H/after/$(basename "$f")" null: 2>&1)"; echo "$f"; done` — Expected: `0` on every line. Any non-zero: open both images, fix the SCSS (never the screenshot), re-run.

### 2: Build and grep the bundle

`pnpm build:source && grep -oE '[0-9]+px' dist/classicy.css | sort | uniq -c | sort -rn | head` — Expected: only `0px` and values inside compiled `@media` preludes; `grep -c 'control-strip-cell-height' dist/classicy.css` ≥ 1.

### 3: Write the docs

AGENT-REFERENCE §8 gains a 'Package knob families' table (family → keys → CSS variables → Platinum values, generated by a one-off script over `platinum.json`) and a 'Pixel literal gate' paragraph; CLAUDE.md Theming gets: 'No bare `Npx` in `src/**/*.scss` (`bin/check-pixel-literals.ts`, run by `pnpm lint`); pixel-matched surfaces read `measurements.<family>` knobs from `platinum.json`, emitted as `--<family>-<key>` by `getThemeVars`.'; plan 0000-aud (the audit) §2.5 and §9 Phase 6 item 3 get a 'Done <date>' line. Spell-check for American English: `grep -n 'colour\|behaviour\|centre' docs/AGENT-REFERENCE.md CLAUDE.md` over the lines you added → none.

### 4: Lint, type-check, commit

`pnpm lint && pnpm exec tsc --noEmit -p . && pnpm test` then `git add docs CLAUDE.md && git commit -m "docs(theme): document package knob families and the pixel-literal gate"` (with the `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` trailer).

### 5: Final verification (plan Phase 8)

`pnpm lint && pnpm exec tsc --noEmit -p . && pnpm test` → all PASS; `node bin/check-pixel-literals.ts` prints nothing and exits 0; `bin/pixel-literal-allowlist.json` is `{}`. Independent of the gate: `grep -rnoE '(?<![\w.-])[1-9][0-9]*(\.[0-9]+)?px' src --include=*.scss | grep -v savers | grep -v '@media' | wc -l` → 0. `verify` skill: run the example app; Appearance → switch Default → Azul → Default; `getComputedStyle(document.querySelector('.classicyDesktop')).getPropertyValue('--control-strip-cell-height')` → `22px`; Control Strip, a menu, a balloon and the pager in Apple Guide look unchanged. Stop background dev servers started by this plan.
