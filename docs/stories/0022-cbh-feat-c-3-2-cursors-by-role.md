# C 3.2: Cursors by role

## Problem Statement

Audit §4.2: cursors reach the screen two ways — `useClassicyCursor.ts` reads `ClassicyIcons.ui.cursors` at call time, while `ClassicySplitView.scss:52-74` and `PDFViewerDocument.scss:37-44` use raw relative `url()`s that no package can swap — and there is no default arrow. Umbrella 0002-ldj pins `registerClassicyCursors(packageId, Partial<Record<ClassicyCursorRole, ClassicyAssetSource>>)` and `--classicy-cursor-<role>` variables.

This story draws the classic Macintosh arrow as `cursor-arrow.svg`, registers Platinum's cursor roles from `platinumAssets.ts` (including the four directional roles `ClassicySplitView` drags with), makes `useClassicyCursor` resolve roles through the registry, and rewrites the SCSS `url()`s to `var(--classicy-cursor-*)`. Behavior is unchanged: `setCursor()` with no role still clears to the browser arrow.

**Impact:** Without it the two SCSS files keep compile-time cursor art that a second package cannot replace, and C 6.1's `grep` gate for `assets/img/ui/cursors` fails.

## Steps

### 1: Write the failing test

`src/SystemFolder/SystemResources/Cursor/useClassicyCursor.test.tsx` (imports `platinumAssets` for its side effect; `renderHook`):
```ts
it("sets the body cursor from the registry for a role") // setCursor("resizeLr"); expect(document.body.style.cursor).toBe(`url(${ClassicyIcons.ui.cursors.resizeLr}), auto`)
it("the arrow role resolves to the Platinum arrow file") // expect(resolveClassicyAsset("cursors","arrow")).toMatch(/cursor-arrow/)
it("clears the body cursor with no role") // setCursor("watch"); setCursor(); expect(document.body.style.cursor).toBe("")
it("an unregistered role clears instead of writing url(undefined)") // setCursor("ibeam"); expect(document.body.style.cursor).toBe("")
it("every role SplitView drags with is registered") // for u,d,l,r: resolveClassicyAsset("cursors", dragCursorName[k]) defined (export dragCursorName or duplicate the four roles in the test)
```

### 2: Run it to verify it fails

`pnpm exec vitest run src/SystemFolder/SystemResources/Cursor` — Expected: FAIL — `resolveClassicyAsset("cursors", …)` is undefined.

### 3: Generate cursor-arrow.svg, register the cursors, rewrite useClassicyCursor.ts

`cursor-arrow.svg`: a 16×16 `shape-rendering="crispEdges"` SVG (`viewBox="0 0 16 16"`, `width="16" height="16"`, 1×1 `<rect>`s) from the classic Macintosh arrow bitmap (Inside Macintosh, QuickDraw): data rows (hex, MSB = left pixel) `4000 6000 7000 7800 7C00 7E00 7F00 7F80 7FC0 7C00 6C00 4600 0600 0300 0300 0000` painted black, mask rows `C000 E000 F000 F800 FC00 FE00 FF00 FF80 FFC0 FFE0 FE00 EF00 CF00 8780 0780 0380` minus data painted white; hotspot (1,1); generated by a scratchpad script, only the SVG is committed. `platinumAssets.ts` adds `registerClassicyCursors(PLATINUM, { arrow: art("cursor-arrow.svg"), watch: ClassicyIcons.ui.cursors.watch, hand: ClassicyIcons.ui.cursors.hand, resizeLr: ClassicyIcons.ui.cursors.resizeLr, resizeUd: ClassicyIcons.ui.cursors.resizeUd, resizeU: ClassicyIcons.ui.cursors.resizeU, resizeD: ClassicyIcons.ui.cursors.resizeD, resizeL: ClassicyIcons.ui.cursors.resizeL, resizeR: ClassicyIcons.ui.cursors.resizeR })` (`ibeam`, `crosshair`, `resizeNwse`, `resizeNesw` have no Platinum file; left unregistered). `useClassicyCursor.ts`: `setCursor(role?: ClassicyCursorRole)`; with a role → `const url = resolveClassicyAsset("cursors", role); document.body.style.cursor = url ? `url(${url}), auto` : ""`; without → `""`. `ClassicySplitView.tsx:33-37` `dragCursorName` typed `Record<"u"|"d"|"l"|"r", ClassicyCursorRole>` (values unchanged).

### 4: Rewrite the SCSS url()s and the PDF viewer's zoom cursor variable

`ClassicySplitView.scss:52` → `var(--classicy-cursor-resize-lr) 8 8, col-resize`; `:59` → `var(--classicy-cursor-resize-ud) 8 8, row-resize`; the `@each` at 70-77 iterates `('u', resize-u, n-resize) ('d', resize-d, s-resize) ('l', resize-l, w-resize) ('r', resize-r, e-resize)` and emits `var(--classicy-cursor-#{$var}) 8 8, $fallback`. `PDFViewerDocument.scss:37` → `var(--classicy-cursor-hand) 8 8, grab`; `:44` → `var(--classicy-pdf-zoom-cursor) 10 10, zoom-in`, where `PDFViewerDocument.tsx` sets `style={{ "--classicy-pdf-zoom-cursor": `url("${zoomToolIcon}")` }}` on its root from the `useClassicyAsset("icons","system.sherlock.search")` value it already reads for the tool button. Then `grep -rn "cursors/cursor-" src --include=*.scss` prints nothing.
